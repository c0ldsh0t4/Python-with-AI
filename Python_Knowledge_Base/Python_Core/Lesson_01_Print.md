# 📘 Python Core — Урок 1. Вывод данных (`print`)

## 🎯 Цель урока
Научиться выводить данные в консоль и использовать основные параметры `print()`.

---

# 1. `print()`

Используется для вывода информации в консоль.

## Синтаксис

```python
print(*objects, sep=" ", end="\n")
```

## Пример

```python
print("Python")
```

---

# 2. Параметр `sep`

`sep` задаёт разделитель **между несколькими аргументами**.

```python
print("Python", "SQL")
```

Результат:

```text
Python SQL
```

```python
print("Python", "SQL", sep="-")
```

Результат:

```text
Python-SQL
```

> ⚠️ **Важно:** если аргумент один, `sep` не работает.

---

# 3. Параметр `end`

По умолчанию после `print()` выполняется перенос строки.

```python
print("Hello")
print("World")
```

Результат:

```text
Hello
World
```

```python
print("Hello", end="")
print("World")
```

Результат:

```text
HelloWorld
```

---

# 4. Escape-последовательности

| Последовательность | Значение |
|-------------------|----------|
| `\n` | Новая строка |
| `\t` | Табуляция |
| `\\` | Вывести символ `\` |
| `\"` | Вывести двойную кавычку |

# ❌ Мои ошибки

- `sep` работает только между несколькими аргументами.
- `end=""` убирает перенос строки.
- `\\` выводит один символ `\`.
- `\"` используется для вывода кавычек.
