# 📘 Python Core — Урок 1. Вывод данных (`print`)

## 🎯 Цель урока
Научиться выводить данные в консоль и использовать основные параметры `print()`.

---

# 1. `print()`

Используется для вывода информации в консоль.

## Синтаксис

```python
print(*objects, sep=" ", end="\n")
```

## Пример

```python
print("Python")
```

---

# 2. Параметр `sep`

`sep` задаёт разделитель **между несколькими аргументами**.

```python
print("Python", "SQL")
```

Результат:

```text
Python SQL
```

```python
print("Python", "SQL", sep="-")
```

Результат:

```text
Python-SQL
```

> ⚠️ **Важно:** если аргумент один, `sep` не работает.

---

# 3. Параметр `end`

По умолчанию после `print()` выполняется перенос строки.

```python
print("Hello")
print("World")
```

Результат:

```text
Hello
World
```

```python
print("Hello", end="")
print("World")
```

Результат:

```text
HelloWorld
```

---

# 4. Escape-последовательности

| Последовательность | Значение |
|-------------------|----------|
| `\n` | Новая строка |
| `\t` | Табуляция |
| `\\` | Вывести символ `\` |
| `\"` | Вывести двойную кавычку |

# ⭐ ChatGPT Additions

## 1. input() всегда возвращает строку

Это одно из самых важных правил Python.

```python
age = input("Age: ")

print(type(age))
```

Вывод:

```python
<class 'str'>
```

Даже если пользователь введет:

```
25
```

Python сохранит:

```python
"25"
```

Поэтому для работы с числами нужно использовать:

```python
age = int(input("Age: "))
```

или

```python
price = float(input("Price: "))
```

---

## 2. Разница между / и //

/

Обычное деление.

Всегда возвращает float.

```python
10 / 2
```

↓

```
5.0
```

//

Целочисленное деление.

Возвращает только целую часть результата.

```python
10 // 3
```

↓

```
3
```

---

## 3. Что делает %

%

Возвращает остаток после деления.

```python
10 % 3
```

↓

```
1
```

Используется:

• Проверка четности

```python
number % 2 == 0
```

• Проверка кратности

```python
number % 5 == 0
```

---

## 4. Что делает **

Возведение в степень.

```python
2 ** 5
```

↓

```
32
```

Не путать с умножением.

---

## 5. Конкатенация строк

```python
print("Hello " + "World")
```

↓

```
Hello World
```

Также

```python
"10" + "5"
```

↓

```
105
```

Строки соединяются.

Числа складываются.

---

## 6. divmod()

```python
divmod(17,5)
```

↓

```
(3,2)
```

То же самое что

```python
17 // 5
17 % 5
```

Но за один вызов.

---

## 7. Хорошие имена переменных

Плохо

```python
a
b
x
```

Хорошо

```python
user_name
phone_number
total_price
order_count
```

Код должен быть понятен человеку.

## 8. Константы

В Python настоящих констант нет.

Но принято писать

```python

PI = 3.14
DATABASE_URL = "..."
```

Большие буквы говорят разработчикам:

"Не изменяй это значение."

## 9. Самые частые ошибки новичков

❌ string

✅ str

❌ input() возвращает число

✅ input() всегда возвращает строку

❌ 3 ** 4 = 12

✅ 3 ** 4 = 81

❌ 20 // 6 = 4

✅ 20 // 6 = 3

❌ "10" + 5

## Data Types

int    -> целые числа

## input()

input() всегда возвращает str.

int("10")      -> 10
float("2.5")   -> 2.5

/   деление (всегда float)

**  степень

## Assignment Operators

+=
-=
*=
/=
//=
%=
**=

---

## divmod()

(a // b, a % b)

## Очень важно помнить
